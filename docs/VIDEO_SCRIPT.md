# Hackathon video script

Target runtime: 3:00. The continuous screen capture from 1:05 through 2:10 is 65 seconds with no cuts.

| Time | On Screen | Exact Voiceover Narration |
| --- | --- | --- |
| 0:00–0:15 | Title over the Panda simulation and replay dashboard. | “OmniSim-Agent tests a robot policy against conditions that can expose failures before a hardware trial. This project focuses on the sim-to-real gap for a Franka Panda policy.” |
| 0:15–0:40 | Show the architecture diagram, then the scenario parameters in the terminal. | “The adversary proposes bounded changes to payload, latency, sensing, and actuator conditions. PyBullet runs the policy headlessly, while detectors score risk and record failure events. Failed cases are grouped and reduced to smaller repros.” |
| 0:40–1:05 | Show the source excerpts/evidence panel and the service configuration. | “At runtime, NVIDIA Nemotron runs through Nebius Token Factory. | 1:05–2:10 | **Continuous capture, no cuts:** start with the headless `scripts/run_campaign.py` command and its progress output; keep the terminal visible while campaign events stream from the API; switch to the React-Three-Fiber Replay dashboard and select the failing episode; show the event timeline and torque/velocity charts; return to the terminal while the same campaign stream continues. | “This is one uninterrupted run. The simulator is running headlessly, so the terminal shows campaign progress rather than a simulator window. The API stream reports the campaign stages and detector events as they happen. Now the dashboard opens the failing episode from that campaign. The replay keeps the trajectory, event markers, and measured joint ratios together so we can inspect the failure. The displayed run source is labeled in the interface; a recorded result is not presented as a new live campaign. The evidence and envelope views use the campaign artifacts, while the benchmark panel distinguishes mock data from measured runs.” |
| 2:10–2:35 | Show safe-envelope metrics and verification output, then the generated export files. | “The shield is ordinary deterministic code. Held-out scenarios check the selected envelope after tuning, and the export includes the envelope, ROS 2 parameters, regression tests, verification data, and an HTML report. The checked-in eight-scenario verification is a test result, not a live campaign benchmark.” |
| 2:35–3:00 | Show limitations, repository page, then the demo link placeholder replaced before publication. | “These results apply to the current headless rigid-body simulation.
